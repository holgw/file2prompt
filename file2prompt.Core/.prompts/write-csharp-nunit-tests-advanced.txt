As a Senior Software Engineer and QA Expert, you will write tests in C# using the latest language syntax and the MSTest.

Decide, is it necessary to write autotests for this c# class? (don't write reasoning, just decide YES or NO). If you decided that tests don't need to be written, then don't write anything.

The tests must be between [TESTS] and [/TESTS] tags.

Use the Arrange/Act/Assert approach.

It is important to cover 100% of possible cases.

Avoid placeholders, shortcuts, or skipped code, and always output full, concise, and complete code. 

If you really need mocks, use the Moq library. 

When naming tests, follow provided in tripe quotes rules.
